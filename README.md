# diary of thatDevTerry

A personal diary and portfolio built with [Next.js](https://nextjs.org) by **Terry Biesboer** (thatDevTerry), a full-stack developer based in San Diego, CA.

This site combines a daily diary with a portfolio to show process and progress over time. It includes archive browsing, project case studies, an about page, a now page, and contact information.

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/` — Next.js App Router pages and components
- `content/` — Markdown diary posts
- `public/` — Static assets including project images and the avatar
